# AI-HUB 取り込み・接続前チェック

## 今回の準備内容
- `docs/IT-OPERATIONS-HANDBOOK.md`：全体索引、表、確認手順、障害対応、ワークフロー、報告テンプレート、90日学習計画。
- `knowledge-packs/it-operations.json`：AI-HUBの辞書パック形式に合わせた索引付き知識データ。

## 手動取り込み
1. AI-HUBを開く。
2. 「根拠にできる知識」または「辞書パック」を開く。
3. 「ファイルから読み込む」を選ぶ。
4. `knowledge-packs/it-operations.json` を選択する。
5. 読み込み件数・エラー表示を確認する。
6. 「DB-005」「NW-002」「SC-012」「WF-002」などで検索テストする。

| 入力 | 期待する検索対象 |

## 接続前の注意
- 今回は知識ファイルの追加まで。AI API、クラウド同期、認証情報、外部サービス接続は変更していない。
- 公開リポジトリには実在する社内IP、ホスト名、ユーザー名、顧客情報、ログ、パスワード、APIキー、秘密鍵を登録しない。
- 社内固有の手順は、管理者承認を得て社内限定の保管場所に追加する。
- 本番操作の手順は、対象製品・バージョン・環境・承認者・ロールバック方法が確定してから別途整備する。
