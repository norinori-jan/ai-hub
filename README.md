# AI-HUB｜社内ITナレッジセンター

データベース・社内インフラ・情報セキュリティ・運用業務を、**索引からすぐ探せる**ように整理したナレッジ集です。

> この追加は「接続前の準備」です。AI API・クラウド同期・外部サービスへの接続設定は変更していません。

## アプリ画面

- [AI-HUBを開く（index.html）](index.html)：下部メニューの「📊 実務」から、索引検索・詳細・確認手順・障害初動・報告書テンプレートを使えます。
- 実務画面にはDB/NW/SV/AD/SC/BK/OP/WFの分野別絞り込み、学習済みチェック、30日集中学習計画を追加しました。
- 教材は `knowledge-packs/it-operations.json` を画面起動時に読み込みます。GitHub Pages上で動作させる場合は、リポジトリのPages公開設定を有効にしてください。

## 仕事中の使い方

1. 用語や索引（例：`NW-002`、`DNS`）で探す。
2. 意味と「確認すること」を読む。
3. 障害なら「共通初動」と該当する障害表を見る。
4. 作業は申請・承認・変更管理・戻し手順を確認する。
5. 対応後は報告テンプレートで事実と推測を分けて記録する。

## 安全上の注意

- 公開リポジトリには実在の社内IP、ホスト名、ユーザー名、顧客情報、ログ、パスワード、APIキー、秘密鍵を登録しないでください。
- ここにある内容は一般的な学習用です。実際の本番作業では会社の規程、製品バージョン、承認済み手順を優先してください。
- 本番DBの更新・削除、サーバー再起動、Firewall/権限変更、端末初期化は独断で行わないでください。

## オフライン利用（PC・iPhone・Android）

AI-HUBはPWAとしてホーム画面／デスクトップに追加でき、教材を端末内にキャッシュしてオフライン利用できます。

1. インターネット接続中に [AI-HUB](https://norinori-jan.github.io/ai-hub/) を開き、読み込み完了まで待ちます。
2. 画面上部の「オフライン利用」から「オフライン用データを保存・更新」を押します。教材・実技問題・ガイドを端末に保存します。
3. PCはChrome/Edgeの「アプリをインストール」、iPhoneはSafariの共有→「ホーム画面に追加」、AndroidはChromeメニュー→「アプリをインストール／ホーム画面に追加」を選びます。
4. 一度アプリを起動して教材を表示できることを確認してから、機内モード等でオフライン動作をテストします。
5. 教材を更新するときはオンラインでアプリを開き、再度「オフライン用データを保存・更新」を押します。

**オフラインで使えるもの：** 索引・詳細説明・実技問題・解説・学習進捗（端末内保存）・同梱ガイド。
**ネット接続が必要なもの：** AIへの外部問い合わせ、クラウド同期、オンライン辞書の更新。音声入力は端末／ブラウザの音声認識機能と通信環境に依存します。

初回の保存前は完全オフラインで使えません。端末ごとに初回保存が必要です。PCとスマホの学習履歴は自動共有されず、同期機能を使う場合はネット接続が必要です。
